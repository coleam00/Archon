# Windows investigation evidence

Supporting documents and evidence for the [Windows issues handoff](../../WINDOWS-ISSUES-HANDOFF.md), published at the operator's request.

The records below preserve the exact bytes of the local investigation archive. [manifest.json](manifest.json) records each original relative name, published name, byte count and SHA-256. Historical reports describe the point in the investigation when they were written; the main handoff contains the final implementation and validation status.

Diagnostic TypeScript and PowerShell files have an added `.txt` suffix so archived instruments do not become repository tests or executable project scripts. Remove that suffix when restoring an instrument in a disposable checkout. Absolute paths inside recorded output describe the original Windows host; use the relative names in this index to locate the published evidence. Runtime downloads and scratch application homes are not part of this evidence set.
