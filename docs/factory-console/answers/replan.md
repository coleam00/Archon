# Start over from the plan

On a delivery ask, `replan` sends the item back to planning with what you write in your answer.
What starts next: a new plan run for the item, with your answer passed in. When that plan ends as planned, delivery starts again from the new plan.
What it costs: the work delivered so far may be discarded.
Pick it when the change needs a different approach, or the plan could not be built as written.
If the change is on the right track and only needs more work, pick `send-back` instead: the same builder continues, at the cost of one more delivery run.
