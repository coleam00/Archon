## Choose one action

- `forge`: a class of problem keeps recurring (the same attention label, the same
  mission failure, the same manual step), and a workflow would handle it. Write `need`
  as a complete brief for the forge: the problem, why it matters, why now, the
  outcome, the invariants, and what acceptance looks like. A person approves whatever
  the forge builds.
- `consolidate`: the memory has grown noisy, redundant, stale, or wrong. Return the
  full replacement list in `lessons`: merged, sharpened, and with anything the evidence
  contradicts removed. Keep only lessons that would change what a future mission does.
- `none`: nothing in the evidence justifies a change. This is a good answer when it is
  true. Do not invent work to look useful.

Leave `need` empty unless you forge, and `lessons` empty unless you consolidate.
State your `rationale` in one or two sentences, and quote the specific `evidence`
(counts, run ids, labels) it rests on.
